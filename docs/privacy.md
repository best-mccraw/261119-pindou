# 隐私保护说明草案
上线前由运营者填入主体名称、联系方式、生效日期，并在微信公众平台以实际接口用途完成隐私保护指引配置。

1. 图片：用户主动从相册选择一张图片，小程序会在手机上制作一份用于内容安全检测的压缩副本，临时上传到腾讯云开发，并通过短期授权链接交给微信检测。检测通过后，原图在本机用于裁剪、颜色采样和生成拼豆图纸。原图、生成图纸均留在本机。用户可取消选择，拒绝授权后仍能免费浏览图库。
2. 相册：用户点击保存后，申请保存图片到系统相册的权限。可在微信设置撤销；拒绝后保留当前图纸供再次保存。再次保存可进入设置授权。
3. 身份：云函数向微信检测接口提供当前用户的 OpenID，审核任务使用其散列值限定结果查询。无广告模式不写入每日下载资格或广告挑战记录，不获取昵称、头像、手机号或通讯录。
4. 临时数据：收到检测结果后删除云端图片副本。未收到结果时，云函数在任务到期约 31 分钟后定期清理。删除失败会重试。与检测相关的临时任务和判定记录随后按到期时间清理。图纸存在当前会话内存，导出 PNG 位于微信临时目录，详情退出清理已知导出文件。保存后的相册文件由用户管理。
5. 图库：图库封面与图纸为公开原创素材，浏览和搜索请求经云开发服务处理。应用日志不写入检测图片、临时下载链接或明文 OpenID。运营者应核对平台调用日志的采集和保留设置。
6. 广告：当前版本直接选图和保存，未启用广告展示。后续启用广告时，按实际服务更新隐私说明及后台声明。
7. 用户权利：用户可拒绝图片或相册授权，仍能浏览。关于记录删除与咨询联系【运营者联系方式待填】。无个人中心或额外账号页面。

在微信公众平台更新隐私保护指引，申报相册照片的实际用途，包括压缩副本临时上传、微信内容安全检测和删除机制。核对 chooseMedia / getImageInfo / saveImageToPhotosAlbum 的实际用途。自定义隐私弹窗通过官方 agreePrivacyAuthorization 按钮完成，相册写入仍需系统授权。
