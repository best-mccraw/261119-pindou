# 隐私保护说明草案
上线前由运营者填入主体名称、联系方式、生效日期，并在微信公众平台以实际接口用途完成隐私保护指引配置。

1. 图片：用户主动选择一张相册图片或拍摄图片，用于本机裁剪、颜色采样和生成拼豆图纸。原图不会上传到本项目服务端，不用于训练、营销或长期备份。用户可取消选择；拒绝后仍能免费浏览图库。
2. 相册：用户点击保存后，申请保存图片到系统相册的权限。可在微信设置撤销；拒绝后保留当前图纸供再次保存。再次保存可进入设置授权。
3. 身份：云函数使用微信云开发提供的 OPENID 判断调用身份。当前无广告模式仅查询公开图库，不写入每日下载资格或广告挑战记录，不获取昵称、头像、手机号或通讯录。
4. 临时数据：生成图纸存在当前会话内存，导出 PNG 位于微信临时目录，详情退出尽力删除已知导出文件；系统也会回收临时目录。保存成功后的相册文件由用户管理。
5. 图库：图库封面与图纸为公开原创素材；浏览和搜索请求经云开发服务处理。服务端不记录原图、明文 OPENID 或密钥。微信云开发平台本身可能按其服务规则保留调用日志，运营者应检查并限制日志保留和访问范围。
6. 广告：当前版本直接选图和保存，未启用广告展示。后续启用广告时，按实际服务更新隐私说明及后台声明。
7. 用户权利：用户可拒绝图片或相册授权，仍能浏览。关于记录删除与咨询联系【运营者联系方式待填】。无个人中心或额外账号页面。

后台需核实并申报 chooseMedia / getImageInfo / saveImageToPhotosAlbum 等实际隐私接口用途；相机来源由系统独立授权。自定义隐私弹窗通过官方 agreePrivacyAuthorization 按钮完成，不替代系统相册权限。
