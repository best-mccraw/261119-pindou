# 拼豆图纸 MVP 设计与实施记录
需求依据：用户完整需求，普通实现自行选择，不增加产品确认环节。
采用原生小程序 TypeScript/WXML/WXSS + 微信云开发；不搭独立服务器。图片本地处理；服务端仅维护图库和 OPENID 每日资格。
备选 Web 封装增加平台适配成本；纯本地图库资格无法满足可信时间要求，均不采用。
视觉：纸白 #FAFBF8、墨绿 #153F36、青绿 #237C66、浅绿 #E8F1EB、灰 #64746D、网格 #D5DED7。系统中文字体保障真机可读性，标题 26px、正文 16px、辅助 13px。图纸区域保留方形像素的手工质感，其他区域安静留白。所有内容左对齐，按钮触控高度 >=44px。
生成页：标题 → 原创像素样例 → 上传入口 → 图片裁剪 → 尺寸 → 生成 → 预览。
图库：搜索 → 横向尺寸筛选 → 两列原创图纸 → 分页。
预览：可缩放完整图纸 → 编号开关 → 用豆表 → 保存。
数据：固定 32 色 v1；区域平均 RGB → OKLab 欧氏距离量化。渲染与统计均消费同一图纸。
导出：每格 28px，最大约 2880×3300 PNG；设备失败则拆为 50×50 以内的带全局坐标分图，每张附完整用豆表并明确张数。
广告：无模拟成功入口。生成资格仅在页面本轮内。图库资格由服务器北京时间日期和 OPENID 决定；短期挑战绑定用户与用途，客户端完整播放后核销；不声称客户端事件可防作弊。
验证：核心算法、资格、分页自动测试；微信工具、真机、真实广告、试拼须实际观察后记录。
