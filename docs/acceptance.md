## 微信开发者工具与手机验收步骤
每条记录设备、系统、微信版本、基础库、时间、预期/实际、截图或相册文件；未执行留空。
1. 完成 README 配置和云端部署/导入。检查两页 Tab、中文、键盘、安全区；窄屏及带底部安全区手机。
2. 生成入口关闭/失败广告：不能打开选图；完整播放才打开；取消选图后重选不重复广告。
3. 分别选 JPEG、PNG 透明图、拍摄竖图、镜像方向样本、大于 10MB、大分辨率、不可解码文件。记录裁剪方向、白底合成及错误提示。检查拖动/缩放，不拉伸。
4. 15/30/50/100 和 17×23 生成，统计总数对应 W×H；空输入、小数、非数字、9/101 被拒绝。快速点击、退出页面不能出现继续保存/多轮广告。
5. 返回生成页反复调整不重复广告；点击新一轮必须再看。原图不出现在云存储或日志。
6. 编号开关导出两份 PNG，放大对照每格 Pxx、从 1 开始坐标、每五格粗线、底部全色表；最大尺寸在真机查看可辨认。测试低内存失败分图路径并保存全部。
7. 图库中文搜索、关键词+尺寸叠加、自定义宽高、无结果、断网重试、封面失败、分页。可复制不同 ID 的合法图纸做临时测试数据，验证下一页，再删除测试数据；不混入首批正式素材。
8. 免费详情不能通过系统预览菜单直接保存。图库首次下载完成广告自动保存；第二张免广告。拒绝相册/打开设置/系统保存失败重试，不再看当天广告。
9. 北京时间 23:59 下载一次，00:00 后再点击下载需重看；不要改手机时间模拟服务端。可在隔离测试环境用受控服务端时间做回归，不向正式包加入时间覆盖接口。
10. 生成资格不替代图库资格；图库当日资格不免生成广告。广告重复回调、超时、页面退出、并发请求不重复保存或解锁。
