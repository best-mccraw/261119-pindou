# 拼豆小星球 UI 改版
依据：用户提供的图1（首页）、图2（生成页）、界面设计色彩统一提示词.txt。用户已确定视觉与路由，直接实现。
采用原生界面与用户原图主视觉组合：主视觉通过容器裁切展示，不把整张截图覆盖在页面上；按钮、参数、上传、开关均为真实原生交互。微信导航和胶囊使用系统能力，不复制图片里的假控件。
固定 token：背景 #FCE5E8 → #FFF1DC；卡片 #FFFAF8；主粉 #F58FA7；选中 #F17999；标题 #751C35；正文 #8D5161。系统中文字体，模块20px、正文15px、注释12px；手机触控最小44px。
布局：首页主视觉 → 两个入口 → 标语；生成页引导 → 上传/裁剪 → 参数卡片 → 开始生成。库和详情同步继承新主题。
复用五个组件：ui-button、ui-card、ui-choice、ui-input、ui-switch；共享样式/变量在 styles/theme.wxss。
保留15×15及默认30×30、独立宽高验证、广告资格与本地计算。首页返回后新的生成页实例开始新一轮；详情返回继续当前轮。
验证：路由及编号偏好回归、全部原测试、组件声明与事件静态检查、布局浏览器预览；微信工具与真机需用户复核，不假称完成。

导航更新：按用户最新要求移除全局底部 tabBar。首页两个按钮均用 navigateTo 打开普通页面，图库通过系统顶部返回按钮回到首页；保留底部安全区间距。
